## Timing (the rhythm is everything)

| Element | Length |
|---|---|
| Dit (·) | 1 unit |
| Dah (−) | 3 units |
| Gap inside a letter | 1 unit |
| Gap between letters | 3 units |
| Gap between words | 7 units |

## SOS

`··· −−− ···` sent as **one continuous signal** (no letter gaps), then a pause, then repeat.
- **Light:** flashlight, mirror, phone screen
- **Sound:** whistle, car horn, banging on a pipe
- **Anywhere:** three of anything = distress (3 fires, 3 whistle blasts, 3 shots)

## Prosigns

| Prosign | Meaning |
|---|---|
| CQ | Calling any station |
| DE | "From" / this is |
| K | Over — go ahead |
| AR `·−·−·` | End of message |
| SK `···−·−` | End of contact |
| BT `−···−` | Break / new paragraph |
| AS `·−···` | Wait |
| R | Received |

## Common Q-Codes

| Code | Question / statement |
|---|---|
| QTH | My location is… |
| QRZ? | Who is calling me? |
| QSL | I acknowledge receipt |
| QRM / QRN | Interference / static |
| QRP | Low power |
| QRT | Stopping transmission |
| QRX | Stand by |
| QSY | Change frequency |
| QSO | A contact / conversation |
| QRV | I am ready |

## Learning Tips
- Learn by **sound**, not by counting dots on a chart. Start at 15–20 WPM character speed with extra spacing (Farnsworth method).
- Start with E T I A N M S O — the most common letters.
- CW (Morse) gets through when voice can't: it works with a few watts and a wire antenna.
